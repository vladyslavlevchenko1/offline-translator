## 🔨 Whisper для распознавания речи (build 14, на проверке)

**Зачем:** Gemma хорошо переводит, но на длинных сбивчивых фразах ошибается в распознавании
(«Что мы в основном где работали…», «на выравнивать»). Whisper обучен только на речь и слышит точнее.

**Как будет работать:** микрофон → **Whisper** (речь → текст) → **Gemma** (текст → перевод).

| Что | Как |
|---|---|
| Движок | whisper.cpp, полностью офлайн, собирается в APK через GitHub Actions |
| Модель | `large-v3-turbo` (q8_0, ~870 МБ), качается один раз из приложения, докачка при обрыве |
| Языки | «Я → …» = русский (украинский/суржик тоже поймёт), «… → Я» = 中文 / English / Deutsch |
| Китайский | Подсказка «以下是普通话的句子» → упрощённые иероглифы с пунктуацией |
| Подсказка словаря | Русские термины из «Словаря» подсказываются Whisper, чтобы он лучше слышал «лоток», «липучка», имена |
| Gemma | Новое правило: восстанавливать смысл сбивчивой речи и исправлять явные ошибки распознавания, а не переводить обрывки |
| Переключатель | «Распознавание: Whisper / Gemma» — вернуться на старый вариант одним касанием |
| Время | В карточке видно отдельно: «Whisper X с + перевод Y с» |
| Быстрый режим | Переключатель в окне Whisper: обрабатывает только длину фразы, а не 30 с. Быстрее, но может ошибаться чаще — сравним на тестах |

**Минусы:** +~870 МБ места; +1–5 с на распознавание (замерим на телефоне).
Старый режим (Gemma слушает сама) остаётся без изменений.

**Как включить:** под «Проверять текст» → «Распознавание: **Whisper ⬇**» → «Скачать» (по Wi-Fi, экран не гаснет).
После скачивания Whisper включится сам. ⚙ справа — окно Whisper (быстрый режим, удалить модель).

## 🔨 Build 15: «Авто», история, отчёты о сбоях (на проверке)

**Авто-направление**
- Вверху три режима: **Авто** | Я → 中文 | 中文 → Я. По умолчанию «Авто».
- С Whisper: сначала Whisper смотрит первые ~10 с и решает, кто говорит (русский/украинский или выбранный язык), потом распознаёт на этом языке. На карточке видно «авто: RU → ZH (RU/UA 93% · ZH 7%)».
- С Gemma (без Whisper): Gemma сама определяет язык и переводит в другую сторону.
- Текст, набранный или поправленный руками, — направление по буквам (кириллица = я, иероглифы/латиница = собеседник). Над полем видно «Переведу: RU → ZH».
- Если перевело не туда — кнопка **⇄** на карточке: переводит ту же фразу в обратную сторону (по записи голоса, если она есть).
- Выбранный язык и режим запоминаются.

**История**
- Все переводы сохраняются на телефоне **навсегда** (пока сам не очистишь), видны после перезапуска.
- В истории есть и то, что распознал Whisper/Gemma **до твоих правок** — чтобы проверять качество распознавания.
- **Голосовые** (твои и собеседника) хранятся временно: 1 / 7 / 30 дней (по умолчанию 7), можно выключить.
- Значок 🕘 (рядом с ⚙): «Отправить всё (с голосом)» или «Только текст и отчёты» → ZIP через «Поделиться» (Telegram, почта, Drive) → можно скинуть ИИ для разбора.

**Сбои и вылеты**
- Вылеты Java/Kotlin записываются сразу; вылеты Whisper/модели (нативные), зависания и «закрыто из-за нехватки памяти» — берутся из системного журнала Android при следующем запуске.
- При следующем запуске покажется окно «В прошлый раз что-то пошло не так» + кнопка «Отправить отчёт».
- Ошибки и время каждого перевода пишутся в `logs/app.log` — тоже попадает в архив.

## 🛠 Для меня (технически)

- Код переводчика: `Android/src/app/src/main/java/com/google/ai/edge/gallery/customtasks/translator/`
- Сборка: GitHub Actions на каждый push в `main` (изменения только в `.md` сборку не запускают). APK → Releases, тег `build-N`.
- `versionCode` = номер сборки + 100, `versionName` = `1.0.<сборка>`, подпись — `keystore/release.jks`.
- Список моделей закреплён на Gallery `1_0_20` (`ModelManagerViewModel.kt`). **Не трогать**, иначе модели «потеряются».
- Whisper: `src/main/cpp/` (CMake тянет whisper.cpp `v1.9.5`, JNI → `libwhisper_jni.so`, только arm64, `-march=armv8.2-a+dotprod+fp16`), Kotlin — `translator/WhisperEngine.kt`. Модель `ggml-large-v3-turbo-q8_0.bin` в `filesDir/whisper/`, качается с HuggingFace с докачкой (`.part`).
- Ветки `dev/**` тоже собираются, но релиз публикуется только из `main`. Итог каждой сборки (статус, ошибки, хвост лога) пишется в ветку `ci-logs` — так его видно без входа в GitHub.
- Словарь хранится в настройках телефона (`glossary_v2`); если меняем встроенный словарь, старые строки пользователя переносятся.
- Авто-направление: `WhisperEngine.detectDirection` — отдельный `whisper_state` с окном энкодера 500 (10 с), прогрет один раз; `whisper_lang_auto_detect_with_state`, сравниваем сумму ru+uk+be против zh+yue / en / de. Для Gemma — `buildAutoAudioPrompt`, направление по порядку строк ответа.
- История: `translator/HistoryStore.kt` → `filesDir/history/history.jsonl` + `history/audio/<id>.wav`. Экспорт — ZIP в `cache/exports/` через FileProvider (`file_paths.xml`, путь `exports/`).
- Сбои: `translator/Diagnostics.kt` (ставится в `GalleryApplication.onCreate`) → `filesDir/logs/`: `crash-*.txt`, `exit-*.txt` (+ `*-tombstone.pb` / `*-anr.txt`), `app.log`.
